# Fluxos de Trabalho n8n

Repositório contendo workflows desenvolvidos no n8n para automação de processos e integração entre sistemas.

## Workflow: Processo de Candidatura

Automação de um processo seletivo com as seguintes etapas:

### Funcionalidades
- Recebimento de dados via formulário
- Validação de cargo
- Filtro por pretensão salarial
- Registro de candidatos em planilha (Google Sheets)
- Envio automático de e-mails
- Agendamento de entrevistas via Google Calendar

### Tecnologias utilizadas
- n8n
- Gmail
- Google Sheets
- Google Calendar
